# ⚡ NEXUS - AI Gesture Controller

**NEXUS** is a high-performance, cybernetic-themed Python application that turns hand gestures into seamless mouse and interaction controls using Real-time Computer Vision and Deep Learning.

## ✨ Key Features
- **Cybernetic Glove Overlay:** Real-time HUD gesture tracking with Cyan glow lines and target reticles.
- **Modern Dark UI:** CustomTkinter Glassmorphism Dashboard.
- **Responsive Controls:**
  - ☝️ **Index Finger:** Smooth Cursor Movement.
  - 🤏 **Pinch (Index + Middle):** Left Click.
  - 🖐️ **4 Fingers UP:** Fast Scroll Up.
  - 👇 **4 Fingers DOWN:** Fast Scroll Down.
  - ✊ **Closed Fist:** Pause System Logic.

## 🛠️ Tech Stack
- **Language:** Python 3.13
- **Computer Vision:** MediaPipe (Gesture Recognizer), OpenCV
- **GUI:** CustomTkinter
- **System Automation:** PyAutoGUI
